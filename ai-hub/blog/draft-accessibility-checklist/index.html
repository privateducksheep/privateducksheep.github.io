An accessibility checklist for AI features

Draft: the checks we run before any AI feature ships.

AN✦
YOYou

Work in progress. Streaming text, loading states and generated content each need their own accessibility checks. These are the ones we have so far.

  • Announce when a response finishes, not every new word
  • Keep keyboard focus where it was while text streams in
  • Give the stop button a visible label, not only an icon
  • Check generated text against the reading-level target for the audience
  • Make sure citation links say where they go

Still to add: screen reader testing notes from the October session, and guidance for charts that Query Desk generates.
