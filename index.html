Full-stackBackendHealth tech

Project Sa'Bai

Project Sa'Bai is a student-run NUS project that has held free health and eye screenings in Cambodia since 2006. From Singapore, I was a backend developer on the patient record system its volunteers use on those trips, from March 2025 to February 2026, working in Django REST and PostgreSQL.

I built the APIs for glasses fitting, including astigmatism in the vitals record, plus vision screening, village configuration and patient consults. I also built user sync with Auth0 and role-based access. That came to six merged pull requests in a codebase with 20 contributors, and I documented the payloads for the Next.js frontend team.

What I learned: agree on the payload with the frontend before writing the model, and validate in the serializer so bad data never reaches the database.

Built with
  • Python
  • Django REST Framework
  • PostgreSQL
  • Auth0
  • Next.js (frontend team)
